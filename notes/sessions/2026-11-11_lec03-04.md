## 気づき
- **他者の記述を「誤り」と判定するときは、出典全体で支持と反証の両方を探す。** τ²-bench の CHANGELOG を grep して、最初に当たった行だけで判断し、後ろにあった反証を見落とした
- **課題の手順と違うやり方をしたら、提出物（answer.md）にも書く。** 技術メモに書くだけでは足りない
- **「1 か所だけ変える」課題では、差分に入っている方針の数を数える。** 既にある規則の言い直しを足すだけでも、モデルへの入力は変わる
- **作業の分担を answer.md に明記する。** 自分が判断したことと、Claude Code が行ったことを分けて書く
- **採点の穴は、ベンチマークの論文と同じ形で自分の採点にも現れる。** 「何もしなければ成功」になるタスクは、中身の無い回答でも合格しうる
- 上の最初の 3 点は、メモリ（verify-and-audit）にも保存した
